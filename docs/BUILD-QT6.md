# Qt 6 + CMake build (CEL-1715)

Replaces the qmake-generated `Chiaki iOS.xcodeproj` (removed). Xcode project is now generated by CMake.

Requires: Xcode 27, CMake >= 3.28, Qt 6.8.3 for iOS and macOS host (`aqt install-qt mac ios 6.8.3` and `aqt install-qt mac desktop 6.8.3`, into `~/Qt`).
Deployment target 16.0 (Qt 6.8 LTS minimum). arm64 only: device and arm64 simulator.

    scripts/build-deps.sh                      # Frameworks/*.xcframework (device + simulator)
    scripts/build-qt-ios-sim.sh <qt-src-dir>   # once: Qt has no arm64 simulator slice, see script header

    # device (Qt dir: ios); simulator (Qt dir: ios-sim, built above)
    cmake -S . -B build/iphoneos -G Xcode -DQT_HOST_PATH=$HOME/Qt/6.8.3/macos \
      -DCMAKE_TOOLCHAIN_FILE=$HOME/Qt/6.8.3/ios/lib/cmake/Qt6/qt.toolchain.cmake -DCHIAKI_DEVELOPMENT_TEAM=<team id>
    cmake -S . -B build/iphonesimulator -G Xcode -DQT_HOST_PATH=$HOME/Qt/6.8.3/macos \
      -DCMAKE_TOOLCHAIN_FILE=$HOME/Qt/6.8.3/ios-sim/lib/cmake/Qt6/qt.toolchain.cmake
    cmake --build build/iphoneos --config Release --target chiaki -- -sdk iphoneos CODE_SIGNING_ALLOWED=NO
    cmake --build build/iphonesimulator --config Release --target chiaki -- -sdk iphonesimulator CODE_SIGNING_ALLOWED=NO

Verified on Xcode 27.2: both build, arm64 only, minos 16.0 (platform IOS / IOSSIMULATOR). Not run on device or simulator yet.
`CHIAKI_GUI_ENABLE_SDL_GAMECONTROLLER` is now defined (old project defined nothing).

Source changes for Qt 6: Qt5 `QAudioDeviceInfo` removed (audio already runs on SDL; device list now from SDL),
`setMargin` -> `setContentsMargins`, widgets/OpenGLWidgets/Svg modules, moc/rcc done by CMake (generated `moc_*.cpp`, `ui_*.h` deleted).
Dropped: bitcode, objc legacy flags, x86_64 simulator, hardcoded team id / bundle id (`org.chiaki.chiaki-ios`, change as needed).
